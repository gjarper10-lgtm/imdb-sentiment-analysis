MOVING TO ANOTHER COMPUTER
Use the complete ZIP from the GitHub release, which includes trained model weights.
The normal GitHub source ZIP does not include the large model.pt files.
Extract the complete ZIP, install Python 3.11, open a terminal in the project folder:
  python -m venv .venv
  .venv\Scripts\python -m pip install -r requirements.txt
Then double-click RUN_DEMO.cmd. Initial dependency installation requires internet.
For retraining instructions, see README.md; do not retrain during your presentation.
